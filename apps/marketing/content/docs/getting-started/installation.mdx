# Installation

Use a maintained **Node.js 22 or 24** release. The npm package is `captar`; its command-line binary is `captor`.

```bash
npm install captar
```

The execution API needs no environment variables, provider keys, Captor account, or hosted database. JSONL is the default local store. SQLite uses Node's built-in `node:sqlite`; use a current Node 22+ release with that module available.

```js
import { run, backfill, JsonlRunStore, SqliteRunStore } from 'captar';
```

Use the installed binary through an npm script, or explicitly select its package:

```bash
npx --package=captar captor runs
npx --package=captar captor inspect <run-id>
```

Existing AI integrations can continue using `createCaptar`. Their provider and optional telemetry configuration are documented in the [AI compatibility quickstart](/docs/getting-started/ai-quickstart).
